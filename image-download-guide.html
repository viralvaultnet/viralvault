Image Download Guide

Understand image formats and quality, and learn how to use pictures legally and safely.

Common image formats

  • JPG / JPEG: small files, great for photos. Quality drops a little each time you re-save.
  • PNG: sharper edges and transparent backgrounds, so it suits logos and screenshots. Files are larger.
  • WebP: a modern format that is usually smaller than JPG or PNG at similar quality. Most browsers support it.
  • SVG: vector graphics that stay sharp at any size. Ideal for icons and simple logos.

Choosing the right size

Bigger is not always better. A full-width website image rarely needs to be wider than about 1600 pixels. Resize before uploading so your pages load fast, especially for visitors on mobile data.

Check the license first

Finding an image online does not mean you may use it. Before using a picture on a website, social media or in a commercial project:

  1. Look for the license on the page where you found the image.
  2. Prefer libraries that clearly state free-to-use terms, such as Unsplash, Pexels or Pixabay.
  3. Check whether credit is required and whether commercial use is allowed.
  4. Keep a note of where the image came from and the license at the time.

Downloading safely

  • Use the site's own Download button whenever it is available.
  • Avoid sites that force you to install software or browser extensions just to save a picture.
  • Scan downloaded files if your device offers it, and be careful with unknown file types like .exe.
Only download and use images you own or have permission to use. Respect the creator's copyright.
